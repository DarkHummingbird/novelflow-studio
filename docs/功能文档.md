# 续章工坊 · 功能文档

适用范围为桌面浏览器。项目只有一个用户入口 [续章工坊](http://127.0.0.1:4173/)，运营在 [管理后台](http://127.0.0.1:4173/admin) 配置服务。

## 1. 从录屏到续章

1. **选择录屏。** 上传小说正文的滚动录屏。当前支持 MP4、MOV、M4V，最长 3 分钟、最大 100 MB。建议从上往下慢慢滚动，让相邻画面保留几行相同文字。
2. **识别文字。** 页面显示上传和识别状态，可以取消。服务端按时间抽取画面、识别文字并拼接。遇到相邻画面无法可靠拼接时，提示核对可能的漏段。
3. **确认前文。** 可打开「对照原录屏」，在前文编辑框内删掉多余内容、改错字、补漏段。前文限 1–8,000 个非空白字符，含标点。确认后才可点击「开始续写」。待确认的前文草稿在本机浏览器保存，刷新后仍需确认。
4. **分析前文。** 选续写档位和短、中、长，点击「开始续写」。系统以确认后的原文为依据，展示主线、主要人物、当前矛盾或待解事项，以及录屏停住的场景，并制定分段安排。分析未完成时可重试，本次不扣费。
5. **分段续写。** 主笔从前文最后一句往下接，每段写完后记录已经发生的事、人物状态变化和待解事项，交给后续段。各档目标约 4,000、6,000、8,000 字，受模型档位的输出上限限制。正文边生成边显示，可以停止。
6. **读完和留存。** 支持复制正文或下载 TXT，页面显示「由 AI 生成，仅供参考」。选择「换一篇」会清空当前前文和结果。刷新可恢复保存的前文，需下载或复制才能留存当次续章。

## 2. 备用文字输入

没有录屏时点击「粘贴文本」打开前文编辑框，或点击「上传 TXT」在浏览器导入 UTF-8 文件。TXT 文件上限为 96 KB，续写前文仍须符合 8,000 字上限。文字方式和录屏方式共用同一续写、质检与结算流程。

## 3. 账号、订阅与余额

| 情况 | 行为 |
| --- | --- |
| 游客试用 | 运营开启首篇免费后，符合条件的游客可试一篇。同 IP 和并发限制仍适用 |
| 网页登录 | 输入手机号和 6 位短信验证码。首次验证自动创建账号，验证码有效期 5 分钟，最多验证 5 次 |
| 购买订阅 | 显示售价、有效天数和篇数。支付确认后立即发放权益，按有效期扣减篇数。到期可自行续购 |
| 余额充值 | 选择后台配置的金额，通过在线收银台付款。确认后实付金额等额进入账户余额 |
| 支付订单 | 显示待支付、已入账或已关闭。返回页面会核对支付结果，也可手动刷新订单状态 |
| 录屏识别 | 不扣篇数或余额，服务器同时处理一个识别任务并按 IP 限流 |
| 续写结算 | 各档位一律优先扣 1 篇有效订阅额度。余额付费时使用用户所选档位显示的单篇价格，未定价的档位沿用基础单价。报价不一致时会要求按新价确认 |
| 失败、取消或降级 | 结算前失败或取消不扣费。单段未通过时最多修订一次，降级交付不扣费 |

续写合格结算要求各段达到分段目标的 85%（取整），总字数达到所选目标的 80%，且正文格式、与紧邻上文的直接重合、重复率等检查通过。生成状态和扣费通过同一事务更新。

## 4. 管理后台

| 区域 | 能力 |
| --- | --- |
| 登录 | 本机可启用仅密码登录。配置 TOTP 的后台使用独立管理员密码和动态码，支持退出 |
| 模型与开关 | DeepSeek 和 Gemini 各保存一次 Key，可查询可用模型。同一家可添加多个档位，独立设置名称与余额单价，并测试、启停或设默认。运营区单独管理公告、暂停和首篇免费 |
| 订阅与定价 | 配置订阅价格、有效天数、篇数，设置充值金额和余额续写的单篇价格，管理上下架 |
| 支付订单 | 查看订阅和充值订单、金额、手机号和支付状态 |
| 用户 | 按手机号查询、调整篇数、封禁或恢复 |
| 用量 | 查看成功率、延迟、模型 tokens、估算成本、失败分布和余额扣款 |

## 5. 核心接口

- `POST /api/ocr` 接收原始视频文件，返回拼接文字、可疑断点数和识别画面数。
- `POST /api/generate` 接收前文和目标长度，通过 SSE 依次返回前文分析与续章。`POST /api/generate/:id/cancel` 取消本人任务。
- `GET /api/me` 和 `GET /api/plans` 提供权益与套餐信息。手机号会话可创建订单、查询订单或继续支付。Stripe 支付通知发送到 `POST /api/payments/stripe/webhook`。
- `/api/admin/*` 除登录配置查询和登录接口外，需后台会话。

从登录、支付到下载续章的操作顺序见 [用户全流程](用户全流程.md)。当前交付边界与运行方式见 [项目说明书](项目说明书.md)。
